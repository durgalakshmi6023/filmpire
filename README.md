# Filmpire – Movie Discovery App

Filmpire is a movie discovery web application built using React.js, Redux Toolkit, Material UI, and The Movie Database (TMDB) API.

## Features
- Browse popular movies
- Search for movies
- View movie and actor details
- Light and dark mode
- Watchlist and favorite movies
- Voice assistant integration using Alan AI

## Technologies Used
- React.js
- JavaScript
- Redux Toolkit
- React Router
- Axios
- Material UI
- TMDB API
- Alan AI

## Getting Started

1. Install Node.js.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Install dependencies:

   `npm install --legacy-peer-deps`

5. Create a `.env` file using `.env.example` as a guide.
6. Add your TMDB API key to the `.env` file.
7. Start the application:

   `npm start`
